# **🎾 Ball Bounce & Fragmentation Simulation**  

This **Pygame-based physics simulation** models a bouncing **parent ball** that spawns **daughter balls** upon impact with the ground. With **realistic gravity, elastic collisions, and dynamic color changes**, this visually engaging experiment brings physics concepts to life!  

---

## **✨ Features**
✅ **Gravity Simulation** – The ball accelerates downward and rebounds dynamically.  
✅ **Fragmentation on Bounce** – The main ball generates **smaller balls** upon impact.  
✅ **Color-Changing Effect** – Daughter balls change color each time they bounce.  
✅ **Randomized Trajectories** – Daughter balls scatter at **random angles** for uniqueness.  
✅ **Wall Collisions** – Balls bounce off the screen edges for continuous movement.  

---

## **🎮 How It Works**
- A **red parent ball** falls under **gravity** and bounces on the ground.  
- On **each bounce**, it spawns **a smaller daughter ball** with **randomized movement**.  
- The daughter balls **change color dynamically** upon bouncing.  
- The simulation runs continuously until **closed manually**.
